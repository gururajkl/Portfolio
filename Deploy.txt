✅ Vercel deployment steps for this app
Since this is a Vite React portfolio, Vercel is a very good fit.

1) Push the project to GitHub
Make sure the repo contains the app folder at portfolio, not just the parent folder.

2) Import it into Vercel
Go to https://vercel.com
Click “Add New…” → “Project”
Import your GitHub repo
3) Set the root directory correctly
This matters for your setup:

If the repo root is the parent folder and the app is inside portfolio, set:
Root Directory: portfolio
If the repo itself is the app folder, leave it as the root.

4) Use these build settings
Vercel should detect Vite automatically, but confirm:

Framework Preset: Vite
Build Command: npm run build
Output Directory: dist
No backend config is needed for this portfolio.

Quick deploy checklist
Repo is connected to GitHub
Root directory is set to portfolio if needed
Build command is npm run build
Output is dist
Click Deploy

Run this in the app folder:


If the preview looks right locally, Vercel should deploy correctly too.
